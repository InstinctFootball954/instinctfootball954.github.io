# Instinct Football 954

Website for Instinct Football 954, live at https://instinctfootball954.github.io

## What's in this repo

| File | Purpose |
| --- | --- |
| `index.html` | The website. Settings (Square links, group dates, photos, videos, fields, Instagram) are in the SETTINGS block near the bottom. |
| `waiver.html` | Online waiver. Signatures go to the Google Sheet through Google Apps Script. Paste the Apps Script URL into `SCRIPT_URL` near the bottom. |
| `404.html` | Page shown for broken links |
| `robots.txt`, `sitemap.xml` | Help Google find and list the site |
| `manifest.webmanifest`, `sw.js` | Make the site installable as a phone app. Pages always load fresh online, so updates reach the app automatically. |
| `.nojekyll` | Tells GitHub Pages to publish the files as-is |
| `googleda2754c19190e899.html` | Google Search Console ownership check. Do not delete. |
| `images/` | Site photos (WebP), link-preview image, home-screen icon |

## Updating

The repo should always match the latest site folder exactly. Replace the whole folder with the new version, commit, and push. Earlier versions stay in the commit history.
